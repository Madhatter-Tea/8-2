# 8-2
How can I ensure that my code, program, or software is functional and secure?
The code itself doesn't interact with the internet. There were also JUnit tests performed to ensure the code not only worked, but was able to handle issues that may arise.

How do I interpret user needs and incorporate them into a program?
I identify what the customer is asking for and modify the product so that the customer needs are a part of the core.

How do I approach designing software?
I focus on the end state and work backwards on what I need to do to reach that state.
